# Repository instructions

Read and follow `instructions/global.md` and `instructions/security.md` before working in this repository. Resolve these paths relative to this repository root.

Before infrastructure work, also read `context/infrastructure.md`.

For planning and specification work, read `instructions/planning.md` and the Superpowers skills it references.

For other skill-driven work, use the relevant vendored skill under `vendor/mattpocock/skills/` when it is installed by the harness.

Before configuring or using MCP servers, read `mcp/README.md`. Their canonical definitions live in `mcp/servers.json`.

Keep shared instructions and personal context in their canonical files. Future agent adapters should reference or generate from those files rather than duplicate rules manually.
